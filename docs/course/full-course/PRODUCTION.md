## Source corrections identified in this build

- Producer CE deadline: Insurance §10–116(a)(2) says **15 days** before expiration. An MIA CE chart still says 30. Teach the current statute, with an editorial note explaining the discrepancy. §10–408 concerns public adjusters and must not be used as the producer rule.
- Appointments: §10–118 uses the insurer's producer register, written appointment documentation and specified **30-day** duties. Do not import another state's 15-day appointment rule.
- Criminal reporting: §10–126(g) generally runs from initial court appearance, not final conviction; its vehicle-misdemeanor exclusion must be distinguished from the separate adverse-administrative-action rule.
